# Dataset Citation and License Record

## Dataset used

Norbert Elter, **PCB Defect dataset**, Kaggle. The Kaggle dataset description
states that it provides YOLO annotations for six PCB defect categories and an
augmented dataset of 10,668 images.

- Dataset page: <https://www.kaggle.com/datasets/norbertelter/pcb-defect-dataset>
- Accessed: 2026-09-14
- License shown by the dataset page: **Unknown**

## Important submission note

Because the source page declares an unknown license, do not redistribute the
raw images or labels publicly unless the course/project supervisor confirms
that this is permitted. Keep the dataset outside version control; distribute a
link or access instructions to authorized teammates instead.
